# 第二卷·第81至90章细纲（2000字/章）——暴怒楚凌章

**81**(林深暴怒)第七天深夜，林深第四次进入意识场。暗红门前，门面上暴怒用手按着的铁皮位置因长期摩擦透出极淡金属光泽。林深没有叩门中央，用指节叩门框——和叩灰蓝门同样的位置和节奏两下。门内侧暴怒的拳头停了。因为门外的叩门节奏和走廊上无名者每天早上放水杯杯底磕铁窗台只差半秒。林深从意识内袋取出老烟手帕意识复刻，用暴怒叠帆布的动作折成三角放暗红门外地板上——不是送，是放在这里你自己决定看不看。暴怒在门内侧透过门缝暗红脉冲光看到紫晶反射。他认出晶体——他自己在清理日后也曾咳出过一样的颜色。**Hook**:林深叩暗红门框——节奏与无名者杯底磕窗台只差半秒。暴怒认出紫晶——自己咳过，但手上是黑的。

**82**(林深暴怒)暴怒没开门，但暗红门缝从不规则脉冲变成了手指宽微开。林深从缝里看到电车内部——暴怒以现实电车为基础的完美意识复刻，但所有日常物品被移到车厢深处盖在一张旧帆布下，帆布四角用旧电缆线绑在铁环上。暴怒背对门站在帆布前，胳膊垂在两侧，拳头攥紧——不是准备出拳，是从十二岁起就是这个姿势。他不是守护里面不让人进，是守着帆布下的东西不能丢。**Hook**:门缝内电车内部——所有日常被移入深处盖帆布绑电缆。暴怒守的不是门，是帆布。

**83**(林深暴怒)林深推门——门轻易被推开，因为暴怒注意力全在帆布上。他走进电车，在暴怒身后保持距离。帆布下第一件东西——水杯，不是暴怒自己用的杯子，是无名者每天早上放在窗台上的那只。他把杯子从窗台挪到最里面，不是藏起来——是不想共振噪音撞到杯子上。暴怒攥拳是因为他怕自己一不留神杯子会碎。**Hook**:帆布下第一件——水杯。不是藏，是不想共振噪音撞到杯子上。

**84**(林深暴怒闪回)暴怒首次允许林深用泪痣接入他的清理日记忆。十二岁——清理日当天他被编入旧研究所处置组的"收尾小队"——负责检查每间隔离室是否被完全清空。他在C-03的隔离室地上捡到一根被遗漏的旧鞋带。他把鞋带藏在自己手套里没交上去——那是他第一次"保护别人留下的东西"。此后每一天清理日他都故意留东西——所有的旧毛巾碎片、旧铅笔头、旧食堂塑料勺——他把所有不能保护的人和只能替他们留住的东西全放在一个旧工具箱里，用自己唯一能做的事——攥——来确保每样东西都还在原位。**Hook**:暴怒清理日闪回——十二岁收尾小队捡到C-03的鞋带藏在手套里。从那天起每天攥紧工具箱，怕东西不在原位。

**85**(林深暴怒)林深从内袋取出芷夜手带灰蓝线备份——用极轻方式放工具箱旁。暴怒看到灰蓝线——他不认识芷夜但认得线松紧变化的微张力——这是隔音材料外面被人系过的证明。林深说这线是你隔壁那小孩通过墙壁摸到的同一条线。暴怒听完没有开门——他把工具箱里一根备用的旧电车电缆线取出来放在灰蓝线旁边。不是交换——是他在电缆线和灰蓝线交接点上压了极轻压痛。"他妈的四十多年——有小孩送他空气——我不知道空气可以送。"**Hook**:暴怒把旧电缆线放灰蓝线旁边——压住交接点：有小孩送他空气，我不知道空气可以送。

**86**(林深暴怒)暴怒在电车里把帆布下的第二件——小彩虹壶——取出。不是林深要看的，是他自己取。壶口朝下立在他膝盖前——壶身有多处旧凹痕是暴怒每次攥拳后不小心碰到壶面锤出的。他把壶放在工具箱旁——"这东西以前是填外面的——在圣堂巷——那乞丐走之前——南婆洗了壶，说如果以后装在电车里可以用。后来无名者装了水——每天早上浇薄荷。"然后他把自己工具箱里一只早停了的旧秒表放在壶旁——秒针不动，但时间停在和壶上次被南婆洗干净的水痕位置同一分钟内的同一个刻度。**Hook**:暴怒取出小彩虹壶——壶身凹痕是他攥拳时锤的。放旧秒表——秒针停在与壶水痕同一分钟。

**87**(林深暴怒闪回)暴怒第二段清理日回忆——十六岁清理日后，处置组训导员发现他藏东西的习惯，逼他把自己藏的所有物品放在铁盘中。他放了——但把自己唯一没交出去的东西——老研究所食堂一个无名实习生死前留给他的旧清洁工具柜的钥匙——含在嘴里吞了下去。从此他的嘴里多了一把永远吞不掉也吐不出来的旧钥匙。他在电车里沉默至今——不是因为从小不爱说话，是嘴里有钥匙。林深听完从暴怒工具箱中取出那把旧钥匙的备份——不是实物——是他从守夜人描C-07墓碑的指甲频率中复刻出的含钥匙吞咽感的振动。他把振动放工具箱里——"你吞那钥匙的时候不是想记住钥匙——是想记住那个给你钥匙的人——他不知道你名字但他把钥匙给你了。"**Hook**:暴怒吞掉旧实习生给的钥匙——从此嘴里有钥匙说不出话。林深把吞咽的振动复刻回工具箱。

**88**(林深暴怒)第八天下午，暴怒第三次取出帆布下的东西——这次是薄荷盆。盆沿有被他衣角刮脱的半片旧漆。他把盆里的干薄荷叶——已全枯但没丢——放在工具箱旁。"老烟死的时候——我在电车这边——没过去。后来无名者每天早上浇薄荷——我把盆往门口挪——不是怕它死——是怕水不够。"他把盆往门口推回约半米——不再是帆布下——靠近电车门口。"你告诉隔壁那个小孩——我把他空气放在盆后面。这里以前是空的——现在他空气在里面——不是我的——是借给他放。"**Hook**:暴怒把薄荷盆移到门边——空位置给哭泣楚凌的空气。后头以前是空的——现在借给他放。

**89**(林深暴怒清理日闪回)暴怒最后一段清理日回忆——最后一次清理日，他收尾到最后一间隔离室——走廊尽头地下那间——把手放门板上，但没推开。那里面关的是五岁的哭泣楚凌。暴怒站在门外，什么都没收——把工具箱里另一根从其他隔离室捡的旧铅笔放在门口。不是替哭泣楚凌收——是让他自己醒来后看到门外有人放铅笔。暴怒的拳头从那天起没有松开过，但多了这第二件他没有收进工具箱的东西。"——原来那哭哭啼啼的小孩就是四十多年前我没推的那扇门里的。他把空气给了我……我那时候放了根铅笔在他门口——他不知道——但他空气里——有铅笔的木头味。"**Hook**:暴怒最后清理日——在哭泣楚凌门口放铅笔但没推门。哭泣楚凌的空气里有铅笔的木头味——他不知道，但收到了。

**90**(林深暴怒全员)第九天深夜——暴怒在电车里把老烟手帕用自己松拳后的手指——不再是攥——叠成和老烟一样的三角。他知道怎么叠——三年每天看手帕。然后他把工具箱放在手帕上——不是遮住紫晶——是把工具箱的重量放在老烟手帕上，确认帕子不会被风吹走。苏萤小黑板写：「暴怒·第一阶段。——工具箱首次开启。灰蓝线接入。——工具重新排列：电缆线→旧秒表→小彩虹壶→薄荷盆。——他不再藏在帆布下。」林深退出前在暗红门框叩两下——暴怒在门内侧回叩——不是两下，是三下。不是怕——是多了一下。**Hook**:暴怒首次叠手帕——工具箱放手帕上防风吹走。苏萤：不再藏在帆布下。暴怒回叩三下——多了一下。
